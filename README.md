# Gabriel Henrique · Portfólio

Site pessoal feito com HTML, CSS e JavaScript puros (sem dependências).

## Estrutura

```
index.html      → conteúdo da página
style.css       → visual (cores, layout, animações)
script.js       → interações (tema, menu, animações)
assets/foto.jpg → foto de perfil
```

## Publicar no GitHub Pages

1. Crie um repositório (ex.: `portfolio`) e envie todos os arquivos mantendo a pasta `assets/`.
2. No repositório, vá em **Settings → Pages**.
3. Em **Source**, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`. Salve.
4. Em 1–2 minutos o site fica em `https://SEU-USUARIO.github.io/portfolio/`.

## Personalizar

- **Contatos:** em `index.html`, procure `EDITE AQUI` e troque e-mail, WhatsApp, LinkedIn e Instagram.
- **Foto:** substitua `assets/foto.jpg` (proporção 4:5 fica melhor).
- **Cores:** no topo do `style.css`, altere as variáveis em `:root`.
- **Palavras que alternam no topo:** em `script.js`, edite a lista `words`.
